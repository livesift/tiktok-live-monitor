# Security Disclosure

This policy applies to the `tiktok-live-monitor` Public `v0.1.0` release.

Do not disclose vulnerability details, tokens, Cookies, Webhook headers, real accounts, or personal data in public GitHub issues, pull requests, logs, or examples.

Use the repository's [GitHub Security Advisory private disclosure form](https://github.com/livesift/tiktok-live-monitor/security/advisories/new). If that form is unavailable, contact the maintainers through a private channel and include:

- The affected package/tag or commit
- The Node.js, npm, Docker, and operating system environment
- Minimal reproduction steps and the impact
- Redacted logs or a synthetic fixture
- A suggested remediation window, if relevant

Maintainers will acknowledge receipt, assess the impact, prepare a fix, and coordinate release notes. Do not use a public feature or bug issue to track an unpatched vulnerability.
